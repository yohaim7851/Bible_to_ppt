# Bible2PPT

성경 구절을 입력받아 PowerPoint 프레젠테이션으로 자동 생성하는 프로그램입니다.

## 📋 프로젝트 소개

Bible2PPT는 성경 책 이름, 장, 절을 입력하면 해당 구절들을 PowerPoint 슬라이드로 자동 생성해주는 도구입니다. SQLite 데이터베이스에 저장된 성경 본문을 활용하여 PPT 파일을 만들어냅니다.

## ✨ 주요 기능

- **성경 구절 입력**: 책 이름, 장, 절 번호를 입력하여 원하는 성경 구절 선택
- **범위 선택 지원**: 단일 절 또는 절 범위(예: 15-23) 입력 가능
- **자동 약어 변환**: 한글 성경 책 이름을 자동으로 약어로 변환 (예: "창세기" → "창")
- **템플릿 지원**: 사용자 정의 PowerPoint 템플릿 사용 가능
- **설정 저장**: 입력한 정보를 `config.txt`에 자동 저장

## 🛠️ 기술 스택

- **Python 3**: 메인 스크립트 언어
- **python-pptx**: PowerPoint 파일 생성 라이브러리
- **SQLite**: 성경 본문 데이터베이스
- **C#**: 데이터베이스 구조 정의 (Bibles 폴더)

## 📁 프로젝트 구조

```
Bible2PPT/
├── generate_ppt.py          # 메인 Python 스크립트
├── run_script.bat           # 실행 배치 파일
├── config.txt               # 설정 파일 (자동 생성)
├── MyTemplate.pptx          # PowerPoint 템플릿 파일
├── bible.pptx               # 생성된 PPT 파일 (출력)
└── Bibles/                  # 성경 데이터베이스 관련 파일
    ├── bible.db             # SQLite 데이터베이스
    ├── Bible.cs             # Bible 클래스
    ├── BibleBase.cs         # BibleBase 클래스
    ├── Book.cs              # Book 클래스
    ├── BookAliases.cs       # BookAliases 클래스
    ├── Chapter.cs           # Chapter 클래스
    └── Verse.cs             # Verse 클래스
```

## 🚀 사용 방법

### 1. 필수 요구사항

- Python 3.x 설치
- `python-pptx` 라이브러리 설치:
  ```bash
  pip install python-pptx
  ```

### 2. 실행 방법

#### 방법 1: 배치 파일 실행 (Windows)
```bash
run_script.bat
```

#### 방법 2: Python 스크립트 직접 실행
```bash
python generate_ppt.py
```

### 3. 사용 예시

프로그램 실행 후 다음 정보를 입력합니다:

1. **성경 책 이름**: 예) "창세기", "마태복음", "에베소서"
2. **장 번호**: 예) 1
3. **절 번호**: 예) 15 또는 15-23 (범위)
4. **출력 파일명**: 예) bible.pptx (기본값)
5. **템플릿 파일명**: 예) MyTemplate.pptx (선택사항)

**입력 예시:**
```
성경 책 이름을 입력하세요: 에베소서
장 번호를 입력하세요: 1
절 번호를 입력하세요: 15-23
출력 파일명을 입력하세요: bible.pptx
템플릿 파일명을 입력하세요: MyTemplate.pptx
```

**결과:**
- `bible.pptx` 파일이 생성됩니다.
- 각 슬라이드에는 성경 구절이 표시됩니다.
- 구절 형식: `(약어 장:절) 본문 내용`

## ⚙️ 설정 파일 (config.txt)

프로그램 실행 후 입력한 정보가 `config.txt` 파일에 자동으로 저장됩니다:
```
"에베소서 1:15-23"
"bible.pptx"
"MyTemplate.pptx"
```

## 📌 주의사항

- `Bibles/bible.db` 파일이 반드시 존재해야 합니다.
- 템플릿 파일(`MyTemplate.pptx`)이 없으면 기본 템플릿이 사용됩니다.
- 템플릿 파일은 'Title and Content' 레이아웃을 포함해야 합니다.
